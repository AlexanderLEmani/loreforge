# LoreHeim — бриф проекта (для передачи другой нейросети)

> **Назначение документа:** скопируй целиком или по секциям в новый чат, чтобы другая модель понимала продукт, стек, этап и приоритеты без доступа к репозиторию.

---

## 1. Одной строкой

**LoreHeim** — браузерный **математический RPG-тренажёр** для самостоятельного обучения арифметике (сложение → проценты): теория в «Коллегии», практика в «Зале», проверка под давлением в «данжах» и на экзаменах. Не заменяет тетрадь — дополняет её игровой петлёй прогресса.

**Репозиторий:** `loreforge` (GitHub) · **Стек:** Next.js 16 + Supabase + Vercel · **Язык UI:** русский.

## 2. Зачем проект (смысл и аудитория)

### Проблема
Взрослые и подростки, которые **сами** хотят подтянуть базовую математику (работа, вуз, самоуважение), часто бросают сухие курсы. Нужна мотивация, структура и «экзамен под давлением», но без ощущения школьного наказания.

### Решение
RPG-оболочка с **понятной петлёй обучения**:

1. **Тетрадь** (офлайн, ручкой) — обязательный шаг, прописан в UX
2. **Коллегия** — короткая лекция (2–5 мин): зачем тема и один метод
3. **Тренировка** — без HP, active recall, можно с подсказками
4. **Данж (бой)** — таймер, ошибка = урон, desirable difficulty
5. **Экзамен** — 10 вопросов, ~80% для прохода, открытие следующего уровня
6. **Skill tree + лавка** — мета-прогресс, заклинания, экипировка

### Педагогические принципы (зашиты в `lib/curriculum.ts`)
- Active recall (бой/тренировка достают из памяти)
- Mastery learning (экзамен перед новым уровнем)
- Desirable difficulties (таймер в бою)
- Interleaving (комбо-атаки смешивают темы)
- Spaced practice (стрик дней, квесты)
- Dual coding (лекция + тетрадь + бой)

## 3. Технический стек

| Слой | Технология |
|------|------------|
| Frontend | Next.js App Router, React, TypeScript, client components |
| Backend / Auth | Supabase (Postgres, Auth, RLS) |
| Деплой | Vercel |

**Миграции БД:** `supabase/migrations/*.sql` → применять локально `npm run db:push` (Vercel миграции не катает).

## 4. На каком этапе проект СЕЙЧАС

### Версионирование (две шкалы)
- **Контент «Арифметика v1»** — уровни I–IV: сложение/вычитание → ×÷ → дроби → проценты. После экзамена IV игрок = **ур. 5 «выпускник v1»** (`lib/v1-cap.ts`). Уровни 5–6 (смешанные действия, мастер) **запланированы, но не реализованы**.
- **Версия приложения** в `ROADMAP.md` помечена как **v1.3**; фактически на `main` уже есть фичи **между v1.3 и v1.4** (см. ниже).

### Стадия продукта
**Публичная альфа / ранняя бета.** Играбельный полный цикл v1 (ур. 1–4), но:
- готовится **первая когорта тестеров** (20–30 человек)
- **блокер перед когортой:** довести аналитику (PostHog) и стабилизировать happy-path
- контент и баланс ещё полируются
- часть механик свежие (отряды, permanent spells) — могут быть баги у старых аккаунтов

### Последний коммит на main (ориентир)
`92b37fe` — sync выученных заклинаний shop↔battle, справочники CSV в `docs/loreheim-reference/`.

## 5. Что УЖЕ реализовано (функциональность)

### Вход и аккаунт
- Google OAuth
- **Гостевой быстрый старт** («Иоанн») — без Google, прогресс в браузере
- Создание персонажа: имя, **5 рас** с боевыми/XP бонусами, пиксель-аватар

### Карта локаций (маршруты)

```
/                 → Вход
/create-character → Герой
/hub              → Хаб (центр)
/college          → Коллегия (лекции I–IV)
/training         → Зал тренировки
/training/multiplication → Тренажёр таблицы умножения (в т.ч. 11–20)
/grimoire         → Гримуар (свитки техники)
/guild            → Гильдия (данжи, квесты, ранги)
/prepare          → Рюкзак перед боем (до 3 расходников)
/battle           → Бой
/debrief          → Итоги боя + лут
/exam             → Экзамены I–IV
/shop             → Лавка
/character        → Персонаж, экипировка
/skills           → Дерево навыков
```

### Программа обучения (4 игровых уровня контента)

| Ур. | Темы | Коллегия | Данжи | Экзамен |
|-----|------|----------|-------|---------|
| I | ➕ ➖ | Лекция I | Пещера сложения, Пещера вычитания | Экзамен I |
| II | ✕ ÷ | Лекция II | Башня умножения, Пещера деления | Экзамен II |
| III | ½ | Лекция III | Храм дробей | Экзамен III |
| IV | % | Лекция IV | Рынок процентов | Экзамен IV → выпускник |

- **26 свитков техники** (ур. I–IV) — покупка в лавке или дроп, тренировка по тегам
- **Лекции** — текст в коде (`lib/college-lectures.ts`, JSON для III–IV); Supabase `lectures` как legacy/fallback

### Бой
- Раунды: выбор атаки → пример → защита монстра (таймер)
- Базовые атаки: Кулак, Заклятье, Удар напором (cd)
- **Permanent battle spells** (лавка, выучить один раз): Двойной удар, Огненный шар, Штормовой ланс, Арканический взрыв, Тёмный сигил — с кулдаунами
- Streak-крит, hard mode (ручной ввод), бонусы рас и экипировки
- **Расходники:** подсказка, мощь, щит, зелье (+40 HP); неиспользованные возвращаются
- **Монстры:** слабости/сопротивления темам, стойка, заряд ярости, уклонение
- **Чемпионы данжа** (после 10 побед, ~28% шанс): больше HP, ярость, лучший лут, UI «намерений»
- **Отряды** (Арена отрядов, чемпион с миньонами): 2–3 врага, combo/swarm/windup/lifesteal
- **Дебриф:** XP, золото, слава, лут

### Мета и экономика
- **XP** → экзамен · **Золото** → лавка · **Слава (⭐)** → вход в данжи + ранги гильдии
- **15 предметов экипировки** (3 тира) — только дроп/ранги, 5 слотов
- **Skill tree** — ветки по темам, пассивки «Мастер …», разблокировка покупки заклинаний
- **Лут после побед:** ~72% шанс — экипировка, свиток, расходник или золото
- Квесты дня (хаб), квесты гильдии, стрик дней + **daily study timer** (минуты практики)
- Mastery achievements, onboarding 3 шага (тренировка → гильдия → первый данж)

### UX / платформы
- Sidebar + мобильная нижняя навигация
- Адаптивный бой, коллегия, модалки
- LoadingScreen с flavor-текстами
- Звуки (опционально)

### Данные и инфра
- ~30 SQL-миграций
- Fallback-вопросы если БД пуста
- Скрипты: `questions:seed`, `questions:generate`
- Справочник врагов/лута: `docs/loreheim-reference/*.csv`

### Аналитика (частично)
PostHog: `auth_completed`, `character_created`, `dungeon_prepare_enter`, `battle_started/ended`, `exam_started/ended`, pageviews — **воронки в дашборде ещё нужно настроить** (см. ROADMAP v1.4).

## 10. Известные технические нюансы (для контекста)

- **Старые аккаунты:** `users.level` может быть 1 при большом прогрессе — UI использует `effectivePlayerLevel` (skill tree, spells, completed lectures).
- **Миграция `learned_spells`:** нужна в Supabase для permanent spells; без неё fallback на `spell_scrolls`.
- **Лекции в БД vs код:** прод читает fallback из кода; DELETE в Supabase без деплоя не меняет UI.
- **Арена отрядов** — тестовый режим (2–3 врага), id `pack` в guild.

## 11. Как работать с проектом (инструкция для AI-ассистента)

1. **Не ломать педагогическую петлю:** тетрадь → лекция → тренировка → бой → экзамен.
2. **v1 cap:** не добавлять экзамен V / ур. 5 контент без явного запроса.
3. **Минимальный diff:** проект solo/small team, prefer focused PRs.
4. **Перед фичами с БД:** проверить миграцию + `npm run db:push`.
5. **Перед деплоем:** `npm run lint` && `npm run build` (как CI).
6. **Коммиты/пуш** — только по запросу пользователя.
7. **Next.js:** читать локальную доку в `node_modules/next/dist/docs/`.
