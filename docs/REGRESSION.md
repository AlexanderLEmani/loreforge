# Регрессия LoreHeim (v1)

Короткий чеклист перед релизом или после больших изменений. **~15 мин** на десктоп + **~10 мин** на мобилке.

## Гость (быстрый старт)

- [ ] Лендинг → «Войти без почты» → создание персонажа (или хаб, если уже есть)
- [ ] После перезагрузки страницы сессия гостя сохранена
- [ ] Хаб показывает XP / золото без ошибок

## Тренировка

- [ ] Выбор темы → сессия → ответ (варианты и «Сам ввод»)
- [ ] Enter в режиме ввода не «убивает» фокус на мобилке
- [ ] Итог сессии: точность, XP

## Бой

- [ ] Гильдия → данж → prepare (рюкзак) → battle (`?dungeon=add` в URL)
- [ ] Атака → защита → дебриф
- [ ] Побег возвращает в гильдию, расходники не пропадают
- [ ] Legacy URL с русским именем (`?dungeon=Пещера сложения`) всё ещё открывает бой

## Экзамен

- [ ] Экзамен I (или доступный уровень): ввод ответа, Enter, результат
- [ ] При провале — «попробовать снова»

## Мобилка (узкий экран ≤ 430px)

- [ ] Нижняя навигация не перекрывает контент
- [ ] Бой: HUD + вопрос + варианты на одном экране
- [ ] Тренировка: поле ввода и клавиатура
- [ ] Коллегия: формулы не обрезаны

## Аналитика (если PostHog настроен)

- [ ] В PostHog Live events: `auth_started`, `battle_started`, `battle_ended`, `training_session_end`
- [ ] В событиях нет email / имени персонажа
