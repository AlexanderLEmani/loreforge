# LoreForge — карта проекта и версии

Документ описывает, **что уже в игре**, **как нумерируются релизы** и **что планируется дальше**.

---

## Как читать версии

| Префикс | Смысл |
|--------|--------|
| **v0.x** | Альфа: основа игры, контент и механики до стабильной «беты». |
| **v1.x** | **Арифметика v1** — курс от сложения до процентов (экзамены I–IV, выпускник на ур. 5). |
| **v2.x** | Продолжение арифметики: смешанные действия, скобки, «мастер арифметики». |
| **v3.x** | Новая ветка: **алгебра** (уравнения, переменные, графики — отдельный курс). |

**Текущая версия продукта: v1.3** (`main`, коммит `35a6b3d`).

Версии **контента** (экзамен I, коллегия IV) и **приложения** (v1.3) — разные шкалы. В UI «Арифметика v1» = контент до процентов; «v1.3» = релиз кода.

## Снимок v1.3 — что есть сейчас

### Ядро

- Next.js App Router, Supabase (auth + Postgres), деплой Vercel, CI (lint + build).
- Вход: Google OAuth и гостевой быстрый старт («Иоанн»).
- Создание персонажа: имя, раса, пиксель-аватар.
- Хаб: XP, золото, слава, серия, онбординг, счётчик расходников.

### Учёба (4 уровня программы)

| Ур. | Темы | Коллегия | Данж | Экзамен |
|-----|------|----------|------|---------|
| I | ➕ ➖ | Лекции I | Пещера сложения / вычитания | Экзамен I |
| II | ✕ ÷ | Лекции II | Башня умножения / Пещера деления | Экзамен II |
| III | ½ дроби | Лекции III | Храм дробей | Экзамен III |
| IV | % | Лекции IV | Рынок процентов | Экзамен IV → выпускник v1 (игр. ур. 5) |

- **Тренировка** — темы и свитки, статистика, XP/золото, без HP.
- **Тренировка по свиткам** — уровни I–IV (подсказки, лайфхаки).
- **Гримуар** — свитки по уровням, фильтры.
- **Экзамен** — 10 вопросов, ~80% для прохода, очки навыков.

### Гильдия и прогресс

- 6 данжей, вход за **славу** (⭐); скидки и бесплатный вход по **рангам гильдии**.
- Дневные квесты гильдии, клейм наград.
- История забегов.
- Подготовка к данжу: рюкзак до 3 расходников.

### Бой

- Раунды: атака → защита, таймер, streak-крит, hard mode (ручной ввод).
- Босс-усиление при низком HP.
- Расходники: подсказка, мощь, щит, зелье; **неиспользованные возвращаются в запас**.
- Дебриф: награды + лут; одна кнопка «в гильдию».
- Компактный UI (десктоп + мобильный HUD).

### Экономика и мета

- **XP** → экзамен; **золото** → лавка; **слава** → данжи и ранги.
- **5 рас** с боевыми и XP-бонусами.
- **Экипировка** (слоты, бонусы в бою, лут, награды рангов).
- **Лавка**: свитки, расходники, превью свитков.
- **Дерево навыков** (ветки по темам, эффекты в бою).
- **Лут** после побед: золото, расходники, свитки, шмот.

### UX

- Sidebar + мобильная нижняя навигация.
- Адаптив: формулы коллегии, модалки, бой на одном экране.
- Флейворные тексты загрузки (`LoadingScreen`).

### Данные

- 20 SQL-миграций в `supabase/migrations/`.
- Fallback-вопросы, если банк в БД пуст.
- Скрипты: `db:push`, `questions:seed`, `questions:generate`.

## История релизов (что сделали)

### v0.1 — MVP «первый данж»

- Логин, хаб, тренировка, бой в одном данже.
- Базовый Supabase, вопросы из БД.
- Навигация между ключевыми локациями.

- Экран «Собери рюкзак» перед данжом.

### v0.7 — Свитки и тренировка L1

- Тренировка по свиткам (уровень I).

### v0.8 — Уровни III–IV и онбординг

### v1.0 — Публичная бета

## Приоритеты перед первой когорой

| Приоритет | Задача | Почему |
|-----------|--------|--------|
| **1** | Базовая аналитика (PostHog) | Где теряются люди — без этого нечего чинить |
| **2** | Стабильный гостевой вход + один happy-path | Первый контакт не должен ломаться |
| **3** | Ссылка для тестеров (Vercel URL ок) | Домен — косметика на старте |
| **4** | Короткий чеклист для тестера | «Пройди тренировку → данж → скажи что непонятно» |

## План версий (roadmap)

Статусы: ✅ выпущено · 🚧 в работе / ближайший спринт · 📋 запланировано · 💡 идея

### v1.4 — Аналитика + стабилизация беты 📋

**Блокер перед первой когорой (20–30 человек):** без трекинга фидбек = «было прикольно», а не «застрял на prepare / сбежал из боя / не понял экзамен».

#### Аналитика (сделать до рассылки ссылок)

Инструмент: **PostHog** (рекомендация) — бесплатный tier, воронки, retention, опционально session replay. **Plausible** — если нужны только pageviews и простой EU-friendly счётчик без событий.

- [ ] Подключить PostHog (или Plausible) в `app/layout` + env `NEXT_PUBLIC_POSTHOG_*`.
- [ ] Автопейджвью по маршрутам (`/guild`, `/battle`, …).
- [ ] События (без PII в properties — только `level`, `dungeon`, `step`):
  - `auth_started` / `auth_completed` (google | guest)
  - `character_created` (race)
  - `onboarding_step` (step id)
  - `training_session_end` (topic, correct, total, duration_sec)
  - `dungeon_prepare_enter` (dungeon, consumables_count)
  - `battle_started` / `battle_ended` (dungeon, result: win|lose|escape, rounds, mistakes)
  - `debrief_viewed` → `guild_returned`
  - `exam_started` / `exam_ended` (level, passed, score)
- [ ] Воронки в дашборде:
  1. Вход → хаб → тренировка → гильдия → prepare → battle → debrief
  2. Первый данж: guild → prepare → battle → win/lose/escape
  3. Онбординг: шаги 1–3 (training, guild, first_dungeon quest)
- [ ] Retention D1/D7 (вернулся ли после первого дня).
- [ ] Политика: EU cloud / без email в событиях; если аудитория &lt;13 — отключить replay, минимизировать данные.

#### Стабилизация (параллельно или сразу после аналитики)

- [ ] Регрессионный чеклист (бой, экзамен, гость, мобилка).
- [ ] Единые empty/error states на всех страницах.
- [ ] Логирование ошибок (Sentry — отдельно от product analytics).
- [ ] Документация для учителя: «как пройти курс v1 за N недель».

**Домен (кастомный URL)** — nice-to-have для первой когоре; `loreforge.vercel.app` или preview-ссылка не блокирует тест. Кастомный домен — v1.4 или когда пойдёшь в школу/родителей.

## Карта локаций (v1.3)

```
/                    → Вход (Google / гость)
/create-character    → Создание героя
/hub                 → Хаб (центр мира)
/college             → Коллегия (лекции I–IV)
/training            → Зал тренировки (+ свитки)
/grimoire            → Гримуар
/guild               → Гильдия (данжи, квесты, ранги)
/prepare             → Рюкзак перед данжом
/battle              → Бой
/debrief             → Итоги боя
/exam                → Экзамен (I–IV)
/shop                → Лавка
/character           → Персонаж, экипировка, запас
/skills              → Дерево навыков
```

## Карта данных (основные таблицы)

| Таблица / сущность | Назначение |
|--------------------|------------|
| `users` | XP, level, gold, glory, consumables, онбординг, квесты |
| `characters` | Имя, раса, визуал |
| `questions` | Банк вопросов по `dungeon_name` |
| `lectures` | Лекции коллегии по `level` |
| `scrolls` | Свитки гримуара + training tags |
| `dungeon_runs` | История забегов |
| `skill_tree_nodes` / `user_skills` | Дерево навыков |
| Экипировка (owned + equipped) | Шмот и слоты |
| Квесты / claims | Награды гильдии и дневные |

Миграции: `supabase/migrations/*.sql` — применять через `npm run db:push`.
